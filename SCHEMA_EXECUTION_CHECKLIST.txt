TROUBLESHOOTING

If you encounter errors:

Error: "relation already exists"
  → Cause: Tables already exist in database
  → Solution: Drop all tables first or use a clean project
  → SQL to drop all:
      DROP SCHEMA IF EXISTS public CASCADE;
      CREATE SCHEMA public;

Error: "permission denied for schema public"
  → Cause: User doesn't have admin role
  → Solution: Contact project admin or switch to admin account

Error: "syntax error"
  → Cause: SQL syntax issue (rare)
  → Solution:
      1. Check file wasn't corrupted
      2. Re-copy from: supabase/migrations/00_hula_agro_complete_schema.sql
      3. Try again

Error: "timeout"
  → Cause: Query takes too long
  → Solution:
      1. Split the SQL into smaller parts
      2. Execute tables first, then indexes, then RLS
      3. Try again with better network

Query seems stuck (spinning forever)
  → Cause: Long-running operation
  → Solution:
      1. Wait another 2-3 minutes
      2. If still stuck, click "Stop" button
      3. Refresh page and check if tables were created anyway
