✨ COMO TESTAR

Local (Desenvolvimento):
  1. npm run dev
  2. Abra http://localhost:3000
  3. Verá botão "Instalar HULA AGRO"
  4. Clique para testar instalação

Produção (Vercel):
  1. git push origin main
  2. Vercel faz deploy
  3. PWA ativa automaticamente
  4. Teste em celular real

Offline:
  1. Instale o app
  2. DevTools → Application
  3. Abra offline simulator
  4. Desmarque "online"
  5. Continue navegando offline!

Notificações:
  1. App solicita permissão
  2. Aceite notificações
  3. Quando mortalidade > 2%, vai receber notificação
