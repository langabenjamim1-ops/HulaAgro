💻 PARA DESENVOLVEDORES

Variáveis de Ambiente (Opcional)

  # Desabilitar PWA (desenvolvimento)
  NEXT_PUBLIC_DISABLE_PWA=false

  # VAPID para push notifications
  NEXT_PUBLIC_VAPID_PUBLIC_KEY=sua_chave_publica

Gerar Chaves VAPID

  npx web-push generate-vapid-keys

Usar API de Notificações

  import { useNotifications, farmAlerts } from '@/lib/pwa/use-notifications'

  export function MyComponent() {
    const { sendAlert } = useNotifications()

    const handleAlert = async () => {
      await sendAlert(farmAlerts.highMortality(15))
    }

    return <button onClick={handleAlert}>Testar</button>
  }

🔧 CACHE STRATEGY

Arquivos Estáticos (_next/static)
  Estratégia: Cache-first
  TTL: 24 horas
  Limite: 64 arquivos

Imagens
  Estratégia: Cache-first
  TTL: 1 dia
  Limite: 60 imagens

Fontes
  Estratégia: Cache-first
  TTL: 365 dias (nunca expira)
  Limite: 4 fontes

API Calls
  Estratégia: Stale-while-revalidate
  TTL: 1 dia
  Limite: 50 requisições

HTML (Navegação)
  Estratégia: Network-first
  Fallback: Offline page
  Cache: 24 horas
