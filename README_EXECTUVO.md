## 🚀 Como Começar Agora

### Passo 1: Obter API Key do Claude (5 minutos)

1. Visite: https://console.anthropic.com
2. Crie conta ou faça login
3. Gere uma chave API
4. Copie o valor: `sk-ant-v0-...`

### Passo 2: Adicionar Variável no Vercel (2 minutos)

1. Acesse seu projeto no Vercel
2. Vá para: Settings → Environment Variables
3. Adicione nova variável:
   - **Key:** `ANTHROPIC_API_KEY`
   - **Value:** `sk-ant-v0-...` (sua chave)
4. Clique "Save"
5. Redeploy o projeto

### Passo 3: Testar no Preview (5 minutos)

1. Abra o preview da aplicação
2. Clique no botão 💬 (canto inferior direito)
3. Faça uma pergunta como:
   - "Quantas aves estão ativas?"
   - "Qual é a mortalidade média?"
   - "Gere um relatório semanal"

**Pronto! Sistema funcionando! 🎉**

## 🆘 Suporte Rápido

### Problema: "IA não funciona"
✅ Verificar: `ANTHROPIC_API_KEY` está definida?
✅ Verificar: Variável está no Vercel (não em .env local)
✅ Verificar: Projeto foi redeploy após adicionar chave

### Problema: "Dados não aparecem"
✅ Verificar: Supabase está conectado
✅ Verificar: Tabelas existem no banco
✅ Verificar: Console mostra erros

### Problema: "Build falha"
✅ Verificar: Comandos `npm install` e `npm run build`
✅ Verificar: Sem erros de TypeScript
✅ Verificar: Arquivo de logs
