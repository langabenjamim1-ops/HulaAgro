TROUBLESHOOTING

SQL execution fails with "relation already exists"
  → Use clean Supabase project or drop existing tables first

SQL execution hangs (spinning for 10+ minutes)
  → Click "Stop" button, try again, or split SQL into parts

"Not authenticated" errors in app
  → Check Supabase credentials in environment variables

"Failed to fetch" errors
  → Verify NEXT_PUBLIC_SUPABASE_URL is correct

Vercel deployment shows errors
  → Check environment variables are set correctly
  → Check TypeScript: npm run build locally first
