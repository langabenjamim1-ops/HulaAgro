## 🔥 Quickstart: Teste Agora

### 1. Clone/Abra o Projeto
```bash
cd /seu/projeto/hula-agro
```

### 2. Instale Dependências
```bash
npm install
# ou
yarn install
```

### 3. Adicione a Chave (Arquivo Local)
```bash
# Crie .env.local (não commita!)
echo "ANTHROPIC_API_KEY=sk-ant-v0-sua-chave-aqui" > .env.local
```

### 4. Execute Localmente
```bash
npm run dev
```

### 5. Abra no Navegador
```
http://localhost:3000
```

### 6. Teste a IA
1. Clique no botão 💬
2. Faça uma pergunta:
   ```
   "Quantas aves estão ativas?"
   ```
3. Aguarde a resposta inteligente!
