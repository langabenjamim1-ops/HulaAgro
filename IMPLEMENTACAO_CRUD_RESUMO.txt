5. FLUXO CRUD COMPLETO
================================================================================

CREATE (Criar):
  User → /create → Form → POST /api/batches → Supabase → Redirect /list

READ (Ler):
  /list → GET /api/batches → Supabase → Tabela com dados

UPDATE (Editar):
  /list (edit button) → /[id]/edit → Form → PUT /api/batches/[id] → Supabase

DELETE (Deletar):
  /list (delete button) → Confirm → DELETE /api/batches/[id] → Supabase

8. COMO TESTAR
================================================================================

1. Execute o SQL:
   - Vá ao Supabase > SQL Editor
   - Cole /scripts/supabase-clean-schema.sql
   - Clique "Run"
   - Aguarde conclusão

2. Acesse a aplicação:
   - Vá para /modules/batches/list
   - Clique "Novo Lote"
   - Preencha campos
   - Clique "Criar Lote"
   - Aparecerá na tabela!

3. Edite um lote:
   - Clique no ícone lápis
   - Modifique dados
   - Clique "Salvar Alterações"

4. Delete um lote:
   - Clique no ícone lixo
   - Confirme exclusão
   - Será removido da tabela e Supabase
